Das Wichtigste in Kürze

  • Bibliogon hat keinen eigenen Server. Deine Bücher, Kapitel, Artikel, Einstellungen und API-Schlüssel liegen ausschließlich in deinem Browser (IndexedDB und localStorage). Der Betreiber sieht sie nicht.
  • Die App setzt keine Cookies und nutzt keine Analyse- oder Tracking-Dienste. Schriften und Skripte sind mitgeliefert und werden nicht von Dritten geladen.
  • Beim Aufruf der Seiten verarbeitet GitHub als Hoster deine IP-Adresse. Ohne dein Zutun ruft die App außerdem einmal täglich bei GitHub ab, ob eine neue Version vorliegt; das lässt sich abschalten. Alles andere geht nur dann an Dritte, wenn du eine Funktion nutzt, die das erfordert.

Hosting bei GitHub Pages

Die App wird von GitHub Pages ausgeliefert, einem Dienst der GitHub, Inc., 88 Colin P. Kelly Jr. Street, San Francisco, CA 94107, USA. Bei jedem Aufruf verarbeitet GitHub die IP-Adresse deines Geräts und die üblichen Verbindungsdaten (Zeitpunkt, aufgerufene Datei, Browsertyp) zu Sicherheitszwecken; nach Angaben von GitHub werden diese Daten nur für die Betriebssicherheit gespeichert und nicht an den Betreiber weitergegeben. Weitere Informationen: GitHub Privacy Statement.

Speicherung im Browser

Alle Daten, die du in der App anlegst, speichert dein Browser lokal in IndexedDB und localStorage; die Dateien der App selbst hält ein Service Worker vor, damit sie offline startet. Diese Speicherung ist für den Betrieb der App erforderlich; es wird nichts an einen Server übertragen. Du kannst deine Daten jederzeit exportieren und in den Einstellungen löschen (Daten: Bild-Cache und Ereignisprotokoll leeren; Gefahrenzone: alles zurücksetzen) oder die Website-Daten in deinem Browser entfernen.

Dein API-Schlüssel für einen KI-Anbieter und ein optionales GitHub-Token werden, falls du sie hinterlegst, ebenfalls nur lokal gespeichert, im Klartext. Du entfernst sie in den Einstellungen (KI-Assistent) beziehungsweise im GitHub-Import.

Automatische Update-Prüfung

Beim Start fragt die App höchstens einmal täglich bei GitHub (api.github.com) ab, ob eine neue Version veröffentlicht wurde. Dabei erhält GitHub deine IP-Adresse; es werden weder ein Token noch Inhalte aus der App übertragen. Du kannst die Prüfung unter Einstellungen › Verhalten abschalten.

KI-Funktionen mit eigenem Schlüssel

KI-gestützte Funktionen (Textvorschläge, Kapitelreview, Metadaten ausfüllen, Grammatik und Übersetzung im Browser) sind nur aktiv, wenn du in den Einstellungen einen eigenen API-Schlüssel eines Anbieters hinterlegst: Anthropic, OpenAI, Google, Mistral, oder eine selbst gewählte Adresse (etwa ein lokales LM Studio oder Ollama). Dann sendet dein Browser den betroffenen Text (Kapitel, Artikel, Buchbeschreibung) direkt an diesen Anbieter. Der Betreiber von Bibliogon ist an dieser Übermittlung nicht beteiligt und erhält keine Daten. Das Vertragsverhältnis besteht zwischen dir und dem Anbieter; es gelten dessen Datenschutzhinweise:

  • Anthropic
  • OpenAI
  • Google
  • Mistral

Importe aus dem Internet

Wenn du ein Buch aus einem GitHub-Repository oder von einer URL importierst, ruft dein Browser die angegebene Quelle ab (bei GitHub: api.github.com, raw.githubusercontent.com); ein optionales GitHub-Token wird nur an GitHub gesendet. Beim Import eines Medium-Archivs lädt dein Browser die Bilder der Artikel von Mediums Bildserver (cdn-images-1.medium.com); Bilder, die dabei nicht lokal gespeichert werden konnten, ruft die Artikelübersicht später erneut von dort ab.

Externe Links

Die App enthält Links zu externen Angeboten (unter anderem GitHub, Amazon KDP, Dokumentation, Spendenplattformen Liberapay, Ko-fi und PayPal). Erst mit dem Klick verlässt du die App; ab dann gelten die Datenschutzhinweise des jeweiligen Anbieters. Es sind keine Skripte oder Schaltflächen dieser Anbieter eingebettet.

Desktop-Version

Die installierte Version läuft vollständig auf deinem Gerät. Dienste wie DeepL, LanguageTool, Sprachausgabe (Text-to-Speech) oder ein Git-Server werden nur dann kontaktiert, wenn du die jeweilige Funktion nutzt und, wo nötig, einen eigenen Schlüssel hinterlegt hast. Eine vollständige technische Aufstellung steht in der Datei PRIVACY.md im Quellcode.
