This policy applies to the public web version of Bibliogon at astrapi69.github.io/bibliogon. If you install Bibliogon yourself (desktop launcher or Docker), you run the app on your own device; the operator of these pages then processes no data at all.

The short version

  • Bibliogon has no server of its own. Your books, chapters, articles, settings and API keys live only in your browser (IndexedDB and localStorage). The operator never sees them.
  • The app sets no cookies and uses no analytics or tracking services. Fonts and scripts ship with the app and are not loaded from third parties.
  • When you open the pages, GitHub, as the host, processes your IP address. Without any action on your part the app also asks GitHub once a day whether a new version exists; you can switch that off. Everything else reaches a third party only when you use a feature that needs it.

Hosting on GitHub Pages

The app is served by GitHub Pages, a service of GitHub, Inc., 88 Colin P. Kelly Jr. Street, San Francisco, CA 94107, USA. On every request GitHub processes your device's IP address and the usual connection data (time, requested file, browser type) for security purposes; according to GitHub these data are kept only for operational security and are not passed on to the operator. More: GitHub Privacy Statement.

Storage in your browser

Everything you create in the app is stored locally by your browser in IndexedDB and localStorage; a service worker keeps the app's own files so it starts offline. This storage is necessary for the app to work; nothing is sent to a server. You can export your data at any time and delete it in Settings (Data: clear image cache and event log; Danger zone: reset everything), or remove the site data in your browser.

Your API key for an AI provider and an optional GitHub token are, if you store them, kept locally as well, in plain text. You remove them in Settings (AI assistant) or in the GitHub import.

Automatic update check

On start the app asks GitHub (api.github.com) at most once a day whether a new version has been released. GitHub receives your IP address; no token and no content from the app is sent. You can switch the check off under Settings › Behaviour.

AI features with your own key

AI features (text suggestions, chapter review, metadata fill, grammar and translation in the browser) are active only if you store your own API key for a provider in Settings: Anthropic, OpenAI, Google, Mistral, or an address you choose yourself (for example a local LM Studio or Ollama). Your browser then sends the text concerned (chapter, article, book description) directly to that provider. The operator of Bibliogon is not involved in this transfer and receives no data. The contract is between you and the provider; its privacy notice applies:

  • Anthropic
  • OpenAI
  • Google
  • Mistral

Imports from the internet

When you import a book from a GitHub repository or from a URL, your browser fetches the source you named (for GitHub: api.github.com, raw.githubusercontent.com); an optional GitHub token is sent to GitHub only. When you import a Medium archive, your browser loads the articles' images from Medium's image server (cdn-images-1.medium.com); images that could not be stored locally are requested from there again when the article list is shown.

External links

The app contains links to external services (among them GitHub, Amazon KDP, the documentation, the donation platforms Liberapay, Ko-fi and PayPal). Only when you click do you leave the app; from then on the privacy notice of the respective provider applies. No scripts or buttons of these providers are embedded.

Desktop version

The installed version runs entirely on your device. Services such as DeepL, LanguageTool, text-to-speech engines or a Git server are contacted only when you use the respective feature and, where required, have stored your own key. The complete technical inventory is in the file PRIVACY.md in the source code.

Contact by email

If you write to the operator by email, your details are stored to handle the request and deleted once the request is settled and no statutory retention obligation stands in the way.

Your rights

You have the right to access, rectification, erasure, restriction of processing, data portability and objection towards the controller, and you can lodge a complaint with a data protection supervisory authority. As the operator does not hold your content, requests for access or erasure concerning it are addressed to your own device: Settings › Data, export or delete.
