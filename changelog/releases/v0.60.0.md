# Bibliogon v0.60.0 — 2026-08-15

The **boot-resilience + PWA-update-flow + release-automation** release.
A field-reported backend boot crash-loop (502 on every request) is fixed,
the UI no longer sticks to German after a slow-network boot, client-side
picture-book PDFs keep full colour, the installed PWA gets a clean update
path (deploy-independent version signal, banner dedup, iOS restart hint),
and the desktop launcher library jumps to 0.28.0. No schema migrations;
existing data + `.bgb`/`.bgp` are unaffected.

## Before you install

Bibliogon runs in Docker. You need Docker Desktop installed and running before starting the launcher.

- [Docker installation guide (English)](https://github.com/astrapi69/bibliogon/blob/main/docs/help/en/install/docker-desktop.md) — includes a "Is Docker safe to install?" section
- [Docker-Installationsanleitung (Deutsch)](https://github.com/astrapi69/bibliogon/blob/main/docs/help/de/install/docker-desktop.md) — mit Abschnitt "Ist Docker sicher zu installieren?"

The launcher manages Docker for a local copy of the Bibliogon repository: it builds the Docker images from your copy and opens the app in your browser. You need the Bibliogon source on disk first (a `git clone`, or the source ZIP unpacked — default `~/bibliogon`); the launcher does not download Bibliogon itself. The first build takes 5-10 minutes (~2 GB disk space).

You do not need the desktop app to try Bibliogon: the offline web app at [astrapi69.github.io/bibliogon/](https://astrapi69.github.io/bibliogon/) runs entirely in your browser, with no install and no backend.


## Action required

**None.** v0.60.0 ships no schema migration. Existing data, backups (`.bgb`) and projects (`.bgp`) are unaffected.

## What's new

### Added
- **PWA update signal `version.json` + banner dedup.** The build emits a deploy-independent `version.json` so the installed PWA can detect a new deploy; the service-worker update banner is suppressed while the GitHub-release banner is shown. (#697)
- **iOS standalone update hint.** On an installed iOS home-screen PWA a reload does not activate a new service worker — the update banners now show a "close and reopen the app" hint on such devices instead of a spinner that never resolves. (#700)

### Changed
- **Desktop launcher: docker-app-launcher ^0.12.1 → ^0.28.0.** Compose start force-recreates the container (an app update can no longer leave the old container silently running), one-step `--update` verb + GUI update button, `--doctor` diagnostics, live log follow, cancellable operations with a cross-process concurrency guard, system light/dark following, and translated failure causes for install/start/update errors. (#702, #705, #709)
- **Release automation** — a one-click Gitflow release workflow plus Makefile orchestration for the mechanical release steps. (#686, #688)
- **Developer tooling** — TDD inner-loop Make targets (red-green-refactor, watch modes, coverage aliases) and a `make pre-commit` target wrapping the all-files hook run. (#690, #693, #716)

### Fixed
- **Backend boot crash-loop: 502 on every request.** The app pre-created an empty `plugins/installed` directory in the data dir at import time; the data-dir migration then saw "both paths exist" and refused to start on every boot for any setup with legacy installed-plugin content. Empty directories no longer count as conflicts, the eager mkdir is gone, ZIP-installed plugins load from the canonical data dir after migration, and `make dev` now aborts loudly when the backend never becomes healthy. (#715)
- **UI stuck in German after boot.** A boot race let a straggling German catalog response overwrite the saved language's catalog on slow networks; stale i18n responses are now discarded. (#714)
- **Client-side picture-book PDF lost colour and quality.** Transparent PNG illustrations composited onto black and all images were re-encoded lossily; images within the size cap now embed their original bytes untouched, and genuine downscales composite on white. Desktop WeasyPrint export was never affected. (#692)

### Tests / Docs
- Web-speech TTS smoke spec fixed (readonly `speechSynthesis` accessor stubbed via `defineProperty`; was red on every nightly). (#712)
- Exploration doc: `editor-menu-model` — scope, twelve settled design decisions, two spin-off findings. (#707)
